Why Not Just Python?

Python guards help when they are called. Heat catches the path that forgot.

Decorators and callbacks are useful, but they are conventions. If a future helper writes a file directly, the policy is bypassed unless a test or reviewer catches it. In this boundary, filesystem egress requires @path_safe. Any path still carrying @user_input fails the build at the sink.
